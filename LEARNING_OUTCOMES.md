# Learning Outcomes

This document defines the competencies required to complete the Python phase of the Learning OS.

The curriculum should be designed backward from these outcomes.

Completing lessons does not guarantee mastery.

Only demonstrated competence counts.

---

# Goal

Upon completing the Python roadmap, the learner should think and work like a junior software engineer who is fully prepared to begin Applied AI Engineering.

---

# Core Competencies

## Problem Solving

The learner can

- Break complex problems into smaller parts.
- Design solutions before writing code.
- Explain their reasoning clearly.
- Choose appropriate data structures.
- Identify edge cases.

---

## Python Fundamentals

The learner can confidently use

- Variables
- Data Types
- Operators
- Strings
- Booleans
- Conditionals
- Loops
- Functions
- Collections
- Modules

without relying on AI.

---

## Intermediate Python

The learner understands

- Object-Oriented Programming
- Exceptions
- File Handling
- JSON
- CSV
- Packages
- Virtual Environments
- Dataclasses
- Enums
- Type Hints

and knows when each should be used.

---

## Professional Python

The learner can explain and apply

- Decorators
- Iterators
- Generators
- Context Managers
- Lambda
- Functional Programming Basics
- Logging
- Regular Expressions
- Requests
- Datetime
- Asyncio
- Testing with pytest

appropriately.

---

## Software Engineering

The learner can

- Read unfamiliar code.
- Refactor messy code.
- Debug independently.
- Write readable code.
- Follow Pythonic conventions.
- Organize projects properly.

---

## AI Preparation

The learner is ready to study

- FastAPI
- Pydantic
- SQLAlchemy
- NumPy
- Pandas
- Git

without struggling with Python syntax.

---

# Graduation Criteria

Python is considered complete only if the learner can independently build medium-sized CLI applications from scratch and explain the reasoning behind their implementation.
