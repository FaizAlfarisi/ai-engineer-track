## D. Code Reading

**D1.**

```python
def tail(folder, name, n):
    p = folder / name
    if not p.exists():
        print("no file")
        return
    with p.open(encoding="utf-8") as f:
        lines = [line.strip() for line in f]
    return lines[-n:]
```

  inside a larger program? (Think about what a function should return.)

**D2.**
```python
def load_jsonish(path):
    raw = Path(path).read_text(encoding="utf-8")
    items = []
    for line in raw.splitlines():
        line = line.strip()
        if not line:
            continue
        key, _, value = line.partition("=")
        try:
            items.append((key.strip(), int(value.strip())))
        except ValueError:
            raise ValueError(f"bad value for {key!r}") from None
    return items
```
- Edge cases: what rows will this skip silently? What does `raise ... from None` do, and why is that deliberate here?
