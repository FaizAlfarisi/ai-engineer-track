## Part 1: Recall (8 pts) — 1 pt each

1. **Context Managers**  
   What are the two special methods that make an object work with `with`? What does `__enter__` typically return?

2. **Context Managers**  
   When using `@contextmanager`, what is the purpose of `yield` in that function?

3. **Regex**  
   What's the difference between `^` and `$` when used in a regex pattern?

4. **Regex**  
   What's the difference between `re.search()` and `re.findall()`?

5. **Datetime**  
   What's the difference between `strftime` and `strptime`?

6. **Datetime**  
   What does `timedelta` let you do?

7. **Asyncio**  
   In `async def foo(): ...`, what do you get when you call `foo()` without `await`? Has it run yet?

8. **Asyncio**  
   What does `asyncio.gather` do vs awaiting each coroutine one by one?

---

## Part 2: Application (7 pts) — 1 pt each

9. **Context Managers (1 pt)**  
   You want to ensure a file is always closed even if an exception occurs. Why is `with open(...) as f:` the correct approach here?

10. **Regex (1 pt)**  
   Given pattern `r"^(\w+)@(\w+)\.com$"`, what would `re.findall` return for `"a@b.com"`? (just the return value/type description in words is fine)

11. **Regex (1 pt)**  
   Why might a greedy `.*` be problematic compared to a non-greedy `.*?`?

12. **Datetime (1 pt)**  
   You have `"2026-10-19 09:14:05"`. Which one would you use to parse it: `strftime` or `strptime`? Write the correct function name and briefly why.

13. **Datetime (1 pt)**  
   If today is `date(2026, 10, 19)` and you want 3 days ago, how would you compute it using `timedelta`? (just the expression/form is fine)

14. **Asyncio (1 pt)**  
   `time.sleep(0.5)` inside an `async def` blocks the event loop. Why is this bad when using `asyncio.gather`?

15. **Asyncio (1 pt)**  
   Name one situation where `asyncio` is the **right** tool, and one where it's the **wrong** tool.
