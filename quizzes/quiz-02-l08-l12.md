        out[r["cat"]] = out.get(r["cat"], 0.0) + r["amt"]

## D. Code Reading

Explain what this does, note edge cases, and any maintainability issues.

**D1.**
```python
def parse_kv(path):
    rows = []
    raw = Path(path).read_text(encoding="utf-8")
    for line in raw.splitlines():
        line = line.strip()
        if not line:
            continue
        key, _, value = line.partition("=")
        try:
            rows.append((key.strip(), int(value.strip())))
        except ValueError:
            raise ValueError(f"bad value for {key!r}") from None
    return rows
```
- What rows does this skip silently, and is that deliberate?
- What happens if a line has no `=` at all?
- Why is `from None` right here?

## E. Apply

   (a CSV file to write).
2. Reads the JSON with pathlib + `json.loads`, using `encoding="utf-8"`.
   Missing or broken file → returns `None`, never prints, never raises.

   `{"category": str, "amount": float, "kind": "income"|"expense"}`.
   Route with `match` by `kind` (income adds, expense subtracts). Records

   print `skipped: <record>` for each.

5. Writes `out_path` via `Path.open(..., "w", newline="", encoding="utf-8")`
   with `csv.DictWriter` — header `category,total`, one row per category
   **sorted alphabetically** by category, totals two decimals.
6. After writing, reads `out_path` back and prints `Summary (N categories):`
   then each row as `category,total` (two decimals).

Covers: L10 Path + Path.open, L11 json + JSONDecodeError + match routing,
L12 csv.DictWriter + newline + type conversion, L8 fail-fast guards +
catch-at-boundary, L9 loader contract (return data, never error strings),
L5 function decomposition.
