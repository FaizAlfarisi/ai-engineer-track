# Assessment Rubric

| Category | Weight |
|----------|-------:|
| Correctness | 25% |
| Logic | 20% |
| Readability | 15% |
| Maintainability | 10% |
| Naming | 10% |
| Pythonic Style | 10% |
| Testing | 5% |
| Performance | 5% |

---

## Mastery Levels

### Level 0 — Not Started
The learner has not studied the topic.

### Level 1 — Familiar
Can recognize concepts and syntax.

### Level 2 — Understands
Can explain concepts with guidance.

### Level 3 — Independent
Can solve standard problems without assistance.

### Level 4 — Proficient
Can debug, refactor, and choose appropriate approaches independently.

### Level 5 — Mastery
Can teach the topic, review others' code, and apply it confidently in real-world projects.

A lesson is considered complete when the learner reaches at least **Level 3**.
