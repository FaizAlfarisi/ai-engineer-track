# Assessment Rubric (V3)

## Review Score Weights

| Category | Weight |
|----------|-------:|
| Correctness | 25% |
| Logic | 20% |
| Readability | 15% |
| Maintainability | 10% |
| Naming | 10% |
| Pythonic Style | 10% |
| Testing | 5% |
| Performance | 5% |

Recorded alongside every score:

- Hint dependency level (0–4)
- Independent-fix ratio (issues fixed alone vs assisted)
- Spec-literalness check (exact-match on required outputs/messages)

---

## Mastery Levels

### Level 0 — Not Started
The learner has not studied the topic.

### Level 1 — Familiar
Can recognize concepts and syntax.

### Level 2 — Understands
Can explain concepts with guidance.

### Level 3 — Independent
Can solve standard problems without assistance.

### Level 4 — Proficient
Can debug, refactor, and choose appropriate approaches independently.

### Level 5 — Mastery
Can teach the topic, review others' code, and apply it confidently in
real-world projects.

---

## Completion Evidence by Tier

The old uniform rule ("Level 3 completes every lesson") is retired.
Completion depends on the topic's tier (`ROADMAP.md`):

### CORE — target Level 4

Understanding demonstrated + independent implementation + at least one
meaningful combination with previous concepts + debugging demonstrated +
Level 4 reached. Stays in rotation until transfer is observed unannounced.

### SUPPORTING — target Level 3

Understanding demonstrated + basic independent implementation + Level 3.

### AWARENESS — target Level 2

Concept understood + can recognize and use a basic example.

### Every completed lesson also requires

Reflection submitted (technical) + code review passed + progress table
updated honestly.

---

## Stage Completion Evidence

- All CORE stage topics at target with transfer evidence
- All SUPPORTING topics at Level 3
- Weekly projects completed
- Stage project completed independently + formal review passed
