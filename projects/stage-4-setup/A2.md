## Type

`[REAL-WORLD]` Stage 4 portfolio sprint

## Goal (one sentence)

Measure dataset quality (duplicates, character-length statistics,
length outliers, missing optional context) and export a cleaned JSONL
file from validated rows while keeping Sprint A1 intact.

## Demo (definition of done)

Start the API (exact command documented in `README.md`), then run both
new endpoints against a sample dataset containing valid rows, duplicate
rows, extra whitespace, and invalid rows:

```text
curl -F "file=@sample.jsonl" http://127.0.0.1:8000/datasets/quality
curl -F "file=@sample.jsonl" http://127.0.0.1:8000/datasets/clean -o cleaned.jsonl
```

- `POST /datasets/quality` returns HTTP `200` with a Pydantic quality
  report (`total`, `valid`, `invalid`, `duplicate_count`,
  `missing_input_ratio`, `instruction`/`response` length stats,
  `outlier_count`, `readiness` verdict).
- `POST /datasets/clean` returns HTTP `200` with a downloadable
  trimmed, deduplicated `.jsonl` file whose rows pass
  `POST /datasets/validate` with `invalid: 0`.
- `POST /datasets/validate` (A1) still passes, and `GET /docs` shows
  all endpoints.

## Scope

In scope:

- [ ] Keep `POST /datasets/validate` working unchanged (plus any small
      A1 refactoring carried forward, if chosen).
- [ ] `POST /datasets/quality`: validate uploaded rows with A1's
      contract first, load valid rows into a Pandas `DataFrame`,
      compute exact duplicates on trimmed `(instruction, response)`,
      NumPy length stats (`min`, `max`, `mean`, `median`) for
      `instruction` and `response`, outlier flags/counts from env-backed
      thresholds (`.env.example`), missing-`input` ratio, and a
      rule-based readiness verdict.
- [ ] `POST /datasets/clean`: trim whitespace, drop duplicates (and
      handle invalid/outlier rows per your `DECISIONS.md` rule), and
      stream/return a downloadable `.jsonl` file response.
- [ ] Reuse Sprint A1 error envelope (`400` empty/malformed/`0` valid
      or clean rows left, `415` unsupported content type) — never `500`
      or `NaN` serialization crashes on expected input/data edge cases.
- [ ] Declare `pandas` and `numpy` in `requirements.txt` and document
      threshold env vars in `.env.example`.
- [ ] Boundary tests green (A1 regressions, quality math accuracy,
      cleaned JSONL re-validation, empty/all-invalid edge cases).

Out of scope (explicitly deferred):

- Persistence / SQLite run history (A3).
- Docker, CI, auth, deployment (A3).
- Semantic / embedding / fuzzy near-duplicate detection, ML/LLM
  scoring.

## API contract

| Method | Path | Request | Response | Errors |
|--------|------|---------|----------|--------|
| POST | `/datasets/quality` | multipart `file` (`.jsonl` or `.json`) | `200` Pydantic quality report (`total`, `valid`, `invalid`, `duplicate_count`, `missing_input_ratio`, length stats, `outlier_count`, `readiness`) | `400` empty / malformed / 0 valid rows · `415` unsupported content type |
| POST | `/datasets/clean` | multipart `file` (`.jsonl` or `.json`) | `200` downloadable `.jsonl` (`Content-Disposition: attachment`) | `400` empty / malformed / 0 clean rows left · `415` unsupported content type |
| POST | `/datasets/validate` | multipart `file` (`.jsonl` or `.json`) | `200` validation summary (A1 contract unchanged) | `400` · `415` |
| GET | `/docs` | — | OpenAPI UI | — |

The learner may refine field/schema names and verdict thresholds in the
slice plan; the contract must stay honest (4xx for expected bad input,
never 500, no tracebacks to clients).

## Concept Kit (just-in-time)

Topics this slice needs (taught in-kit first; nothing silently
required):

- NumPy fundamentals — `ndarray`, `dtypes`, vectorization vs Python
  loops, summary stats (`min`, `max`, `mean`, `median`), boolean masks,
  empty-array traps.
- Pandas fundamentals — `DataFrame` / `Series` from records, `loc` /
  `iloc` / boolean indexing, copy vs view, `isna` / `fillna` /
  `None` vs `NaN`, `.str` string ops, `duplicated` / `drop_duplicates`,
  `iterrows` / `apply` vs vectorization, JSONL export (`to_json` vs
  manual `json.dumps`).
- FastAPI file download & env config — `Response` / `StreamingResponse`
  (`Content-Disposition`, media type), typed `os.getenv` settings.
