`[SETUP]` Stage 4 portfolio setup

verify the local environment so Project A starts clean.


prints `ok`.

## Constraints

- Learner owns the GitHub account and credentials; the AI never handles
  secrets or tokens.
- Use only taught tools (`LEARNER.md` Tool Sync) or PROVIDED.
- Empty repos only: README, LICENSE, `.gitignore`, `.env.example`.
- No starter code, no step-by-step implementation plan.
- Repo names are proposals — learner confirms before creation.
- Never require an untaught tool silently (Docker/CI arrive in A3/B3).
