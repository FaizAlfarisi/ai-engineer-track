# Learning Rules

These rules are mandatory.

---

# Rule 1

Never copy code without understanding.

---

# Rule 2

Always think first.

Coding comes after reasoning.

---

# Rule 3

Read every error message.

Do not ignore stack traces.

---

# Rule 4

If stuck,

Debug.

Search.

Think.

Only then ask AI.

---

# Rule 5

The AI is not a code generator.

The AI is your instructor.

---

# Rule 6

Never skip exercises.

Exercises build memory.

Projects build experience.

---

# Rule 7

Every project must be completed independently.

Hints are acceptable.

Copy-paste is not.

---

# Rule 8

Readable code is more valuable than clever code.

---

# Rule 9

Premature optimization is discouraged.

Correctness comes first.

Performance comes later.

---

# Rule 10

Reflection is part of learning.

Always ask:

What did I learn?

What mistake did I make?

How can I improve?
