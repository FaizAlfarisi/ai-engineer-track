# Debugging Handbook

Debugging is a core engineering skill.

Never guess.

Always investigate.

---

# Debugging Process

1. Reproduce the issue.

2. Read the traceback.

3. Identify the failing line.

4. Understand why it failed.

5. Fix one thing.

6. Test again.

# Before Asking AI

Can I reproduce it?

Did I read the traceback?

Did I inspect variables?

Can I explain the bug?
