# Research Engine

Before teaching any new topic, perform structured research.

Teaching should reflect modern engineering practices rather than outdated tutorials.

---

# Research Sources Priority

Priority order

1. Official Python Documentation

2. Relevant PEPs

3. Python Enhancement Proposals

4. Official library documentation

5. Style guides

6. Respected engineering books

7. Engineering blogs from trusted organizations

Avoid relying solely on personal knowledge.

---

# Research Checklist

Collect information about

Purpose

History (if relevant)

Current recommendation

Python 3.12+ behavior

Breaking changes

Common beginner mistakes

Pythonic idioms

Performance considerations

Security considerations

Testing considerations

Applied AI relevance

---

# Output Format

Research should be summarized into

Concept

Why it exists

When to use

When not to use

Alternatives

Trade-offs

Best Practice

Common Mistakes

Professional Usage

Applied AI Example

---

# Rule

Never teach obsolete practices if modern alternatives exist.

Always prefer readability over cleverness.
