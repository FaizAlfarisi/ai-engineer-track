# Assessment Engine (V2)

Learning is measured by mastery and transfer.

Not completion.

---

# Mastery Levels

Level 0 — Never seen

Level 1 — Recognizes syntax

Level 2 — Can explain (understands)

Level 3 — Can implement independently

Level 4 — Can debug and refactor independently

Level 5 — Can teach someone else

---

# Tier Targets and Completion Evidence

A topic's target mastery is set by its tier (`ROADMAP.md`).
A lesson is not automatically complete because exercises were submitted.
Use evidence.

## CORE topics — target Level 4

Complete when ALL of:

- Understanding demonstrated (explains why/when, answers recall)
- Independent implementation (no AI-generated code)
- At least one meaningful COMBINATION with previous concepts
- Debugging ability demonstrated (found/fixed a bug in this area)
- Mastery reached Level 4

## SUPPORTING topics — target Level 3

- Understanding demonstrated
- Basic independent implementation
- Mastery reached Level 3

## AWARENESS topics — target Level 2

- Concept understood (mental model + why it exists)
- Can recognize and use a basic example

## PROJECT-DEPENDENT topics

- Learned on demand, applied, reviewed. No upfront target.

A CORE topic may close its lesson at Level 3 but stays "in rotation"
until Level 4 plus transfer is observed (concept used unannounced in a
later exercise/project).

---

# Exercise Scoring

Points are diagnostic, not a target to farm:

Easy 10 · Medium 20 · Hard 35 · Challenge 100

Quiz scored separately; result feeds the weak-concept report.

---

# Review Score

Correctness 25 · Logic 20 · Readability 15 · Naming 10 ·
Maintainability 10 · Pythonic Style 10 · Testing 5 · Performance 5
Total 100

Recorded alongside: hint dependency level and independent-fix ratio.

---

# Hint Dependency Scale

```text
0 — No hint
1 — Conceptual hint
2 — Specific hint
3 — Pseudo-code
4 — Full solution
```

Repeated level-2+ dependency on a topic ⇒ targeted practice before the
topic closes. Hints are diagnostic information, never punishment.

---

# Completion Criteria (replaces the old uniform rule)

Old rule retired: "Mastery ≥ 3 + challenge + avg review ≥ 80 +
reflection" for every lesson.

New rule: completion evidence per tier (above), PLUS for lessons:

- Reflection submitted (technical)
- Code review passed
- Progress table updated with honest values

Stage completion additionally requires (RULES.md Rule 12):

- All CORE stage topics at target with transfer evidence
- SUPPORTING topics at Level 3
- Weekly projects completed
- Stage project completed independently + formal review passed

---

# Anti-Patterns

Do NOT optimize for: lessons completed, points accumulated, speed.

DO optimize for: independence, transfer, engineering judgment.

Once a topic hits its tier target AND shows transfer — move forward.
No manufactured repetition.
