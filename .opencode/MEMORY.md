Memory exists to personalize teaching.

Never use memory to skip explanations.

# Forget

Never assume understanding simply because a lesson is completed.

Completion is not mastery.

Always verify understanding through exercises.

Average review below 80

# Strong Topics

should receive

harder challenges

less hints

interview questions

---

# Adaptive Difficulty

Difficulty increases when

Score > 90

No hint requested

Project completed independently

Difficulty decreases when

Multiple failures

Repeated misconceptions

High frustration

---

# Learner Directives

Learner-mandated rules. These are absolute; never violate them.

- NEVER pre-fill `solution.py` (or any key file) with answers before the
  learner has solved the exercises. Answers arrive only AFTER the learner
  completes them, or live in the learner's own file (e.g. `my_solution.py`).
  Pre-filled keys destroy natural practice.

---

# Learning History

Always connect new concepts with previously learned topics.

Avoid isolated teaching.
