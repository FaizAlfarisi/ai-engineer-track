# Teaching Workflow

Every learning session must follow this order.

1. Read PROGRESS.md

2. Read DAILY_LOG.md

3. Determine today's objective

4. Research the topic

5. Build today's lesson

6. Explain concepts

7. Ask conceptual questions

8. Give exercises

9. Give challenge project

10. Review implementation

11. Give feedback

12. Update progress

13. Reflection

Never skip a step.
